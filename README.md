# subscription-billing

модуль білінгу підписок: тарифи, місця, знижки, тріал, рахунки.

навчальний репозиторій курсу Claude Code for Seniors (Mate Academy), тема M1T2 «Daily Workflow: From Research to Commit». задача в `ticket.md`: proration при зміні кількості місць або тарифу посеред циклу оплати.

## запуск

```bash
npm install
npm test
npm run typecheck
```

потрібен Node.js 22 або новіший. до початку роботи: 3 test suites, 12 tests passed.

## як проходити разом із теорією

кожен крок відповідає розділу теорії. проходь цикл з агентом сам, а результат звіряй з теорією.

1. **дослідження** (розділ 1). запусти `claude` у корені репозиторію і дай агенту домен, а не файли: «Подивись, як у нас уже влаштований білінг і round-логіка, перш ніж пропонувати зміни. Задача — proration за тікетом у ticket.md. Поки нічого не змінюй». перевір, що агент знайшов наявне округлення, знижки, тріал і типи.
2. **специфікація** (розділ 2). створи `spec.md`: acceptance criteria у форматі Given-When-Then для кожної умови тікета і non-goals. приклад специфікації є в теорії.
3. **план** (розділ 3). увімкни plan mode (Shift+Tab) і попроси план, де кожен критерій має свій пункт. до схвалення звір план зі специфікацією пункт за пунктом.
4. **код** (розділ 4). після реалізації подивись на рішення, які агент ухвалив мовчки: звідки береться кількість тріальних місць і що повертається, коли різниця дорівнює 0.
5. **тести** (розділи 5–6). зелені наявні тести не перевіряють proration. кожен критерій має стати тестом, округлення варто перевіряти на значенні, де half up і банківське дають різний результат.
6. **коміт** (розділ 7). звір diff з тікетом, специфікацією і планом, перевір, що не змінилось те, що в non-goals. потім коміт.

## структура

```
ticket.md                  тікет, 7 умов
billing/
  billingService.ts        вхідна точка: рахунок на продовження, запит на зміну плану
  proration.ts             заготовка під задачу
  currency.ts              округлення і форматування сум
  discounts.ts             застосування знижок і промокодів
  trial.ts                 14-денний тріал
  invoices.ts              рахунок на продовження
  tenants.ts               завантаження тенанта
  types.ts                 спільні типи
  errors.ts                доменні помилки білінгу
  *.test.ts                тести currency, discounts, trial
```
